# RH Core Web

Proyecto React bootstrapeado con [Create React App](https://github.com/facebook/create-react-app).

## Scripts Disponibles

En el directorio del proyecto, puedes ejecutar:

### `npm start`

Ejecuta la aplicación en modo desarrollo. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

La página se recargará cuando hagas cambios.

### `npm test`

Lanza el ejecutor de pruebas en modo interactivo.

### `npm run build`

Construye la aplicación para producción en la carpeta `build`.

La aplicación estará optimizada y lista para desplegar.
